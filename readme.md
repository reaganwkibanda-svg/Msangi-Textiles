# Madam Rita | Luxury African Fashion Website

Welcome to the official beginner-friendly documentation for the Madam Rita website project. This website is built using **HTML5**, **CSS3**, and **Vanilla JavaScript** to ensure it looks luxurious, high-end, and professional while remaining extremely easy to understand, edit, maintain, and fully equipped with an **alive animated brand logo**, **favicon setup**, **English / Kiswahili language toggle**, **Dark / Light mode theme switcher**, **floating social action buttons (WhatsApp, Instagram, TikTok)**, and **smooth scroll reveal transitions**.

## How to Open the Website Locally
1. Download or clone the project folder onto your computer.
2. Open your web browser (Chrome, Safari, Firefox, or Edge).
3. Drag and drop the `index.html` file directly into your browser window, or right-click `index.html` -> **Open With** -> Choose your favorite browser.
